2026 年，也是我使用 AI 的第三年了。自 2023 年通过印尼虚拟手机注册了 chatgpt 起，再到如今 Cursor 的年费会员，AI 已经融入到了我的编程。作为浪潮里的小浪花，也想回看一下 AI 对我带来的改变。

## “这可比 CSDN 好太多了”

国内的程序员可逃不过 CSDN，初入行业，想快捷查询 API、业界方案和小的 demo 实现，“搬运站 CSDN”可谓是大全。随着工作到 1-2 年，遇到更“专”的问题，CSDN 解决不了，也发现了论坛反复搬运的毛病。开始转向 Stack Overflow 或者 Reddit 上看问题。再往后，接触到工程化的问题，就去 GitHub 看出问题的包版本、看开源 API 实现方式和看 Issue 等等方式去解决问题。我也在 AntV 提过数个问题，和网络对面的朋友一起解决问题。而后，听闻了 Copilot 的名声，国内寻找使用了智谱的插件，coding 过程中的 tab 自动补全起码提升了 30% 的效率。减少了复制工程师做的事情，也帮忙处理了变量命名的大难题。

“ai 出来了！ai 出来了！”看着宣传片里，什么都能解答的对话式交互 ai，感觉多了个智能百度，还能够帮忙做规划。赶紧通过虚拟手机号去注册了一个账号。我也开始把代码片段让 ai 优化，询问有关于微前端之类的问题和可推荐的开源工具。自此，我的 coding 模式上了“高速”。也几乎不用程序员论坛去搜索问题。

## “Cursor 惊为天人”

AI IDE 的概念一出来，Cursor 引入眼帘，再往后是 Trae、Claude Code (cc) 等等。都使用一遍后，作为前端开发者直接购入了年费 Cursor，到现在已经一年多了，期间使用体验都非常好。从 plan 到 agent 执行，包括 CR AI 写的代码也很顺手。

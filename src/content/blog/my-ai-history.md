# 我的 AI 使用历史

2026 年，也是我使用 AI 的第三年了。自 2023 年通过印尼虚拟手机注册了 chatgpt 起，再到如今 Cursor 的年费会员，AI 已经融入到了我的编程。作为浪潮里的小浪花，也想回看一下 AI 对我带来的改变。

## 起-这可比 CSDN 好太多了

国内的程序员可逃不过 CSDN，初入行业，想快捷查询 API、业界方案和小的 demo 实现，“搬运站 CSDN”可谓是大全。随着年限到 1-2 年，更“专”的问题，CSDN 解决不了。那时候就去 github 看出问题的包版本，看开源 API 实现方式，看 Issue 等等方式去解决问题。我也在 AntV 提过数个问题，和网络对面的朋友一起解决问题。而后，入行不过1、2 年，就学会了
